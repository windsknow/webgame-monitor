# 方向归类规则（2026-11-25）

卡片的 `group` 只能是下面七个方向之一，由每周会话按玩法归类。方向标题和说明在 `data/static.json` 的 `groups`。

## 七个方向（每款只归一个）

平台名（Astrocade、Spawn、Verse8、Rosebud、Wavedash、Vibe Jam）**不是方向**，平台上的游戏也按玩法归入下面七个。

1. **把真实世界做成游戏**：用真实地图、地理、城市数据生成主要内容（OpenStreetMap、卫星影像、地籍、真实交通规则）。只是故事设定在某座真实城市的不算。
2. **端游级3D 美术表现力**：3D 画面质量是主要看点（大场景、光照阴影、写实或精致风格化）。平台模板生成的普通低多边形、体素 3D 不算。
3. **游戏复刻与反编译**：已有游戏或 IP 的同人、复刻、移植、反编译，以及"像某款已知游戏"本身就是卖点的作品（例如 Minecraft 题材、CS 式爆破对战、Roblox 的 DOORS、鱿鱼游戏题材）。
4. **多人在线交互**：多人联机、同场、房间对战是核心（含平台上的多人射击、MOBA）。
5. **把大模型当作玩法本身**：运行时大模型参与玩法（角色、对手、旁白、实时生成内容）。
6. **休闲益智与分享比拼**：规则简单、单局短的休闲、益智、街机、放置、模拟经营、换装、解压类，以及每日挑战、能晒成绩的。常规类型做得完整的小游戏（塔防、跑酷、闯关射击、竞速、幸存者类），画面又不突出的，也归这里。
7. **独立精品与巧妙创意**：只放两种。
   - 巧妙创意：核心机制或呈现方式是别人没做过的点子（玩法新颖 N 至少 1 分），而且这个点子就是作品的主要看点。
   - 独立精品：有鲜明作者风格的叙事、美术或体验作品，例如以氛围、叙事、诗意为主的探索小品。
   - 常规类型做得完整（标准 FPS、赛车、塔防、幸存者类、清版动作）不放这里，按画面放 2 或 6。

同时符合几个方向时，按这个顺序取第一个符合的：5 → 1 → 3 → 4 → 7 → 2 → 6。

## 2026-11-25 为什么要重分

- 原来的方向表沿用了基线报告的分节，里面混着平台分组（Astrocade、Spawn、Verse8、Rosebud、Wavedash 与 Far Worlds、Vibe Jam 获奖作品）。
- 自动卡片归方向时，平台上的游戏被直接归到了平台名下：Astrocade 48 款、Spawn 13 款、Verse8 9 款。
- 七个方向里没有"常规类型、做得完整"的位置，Fable52 上大量"常规类型 + 单 HTML 完成度"的作品被放进了"独立精品与巧妙创意"。这一类有 49 款，其中 16 款玩法新颖分是 0。

处理：
- 从 `static.json` 去掉 Astrocade、Spawn、Verse8 三个平台分组，这些游戏按玩法重新归入七个方向。平台来源留在卡片和"发现渠道"筛选里。
- "独立精品与巧妙创意"只留有新点子或鲜明作者风格的；常规类型按画面归到"端游级3D"或"休闲益智"，"休闲益智"的说明相应补了一句。
- Rosebud AI、Wavedash 与 Far Worlds、Vibe Jam 获奖作品这三个平台分组还在（共 11 款，都是基线报告里人工核验过的），等用户确认后再按同样办法处理。

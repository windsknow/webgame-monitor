# 部署步骤

本机没有装 `gh`，下面第一部分需要你自己在 GitHub 网页上操作。

## 一、先在 GitHub 搭通

### 推送前先看一眼会公开什么

GitHub Pages 免费版要求仓库是公开的。公开仓库里任何人都能看到：

- 代码、`config.json` 里的门槛和关键词
- `data/` 下的全部数据：收录库、候选队列、主题判断和备注
- `raw/x/` 下粗筛命中的帖子原文（每天二三十条，都是公开帖子）

**不会**进仓库的（已写进 `.gitignore`）：

- `inbox/x/`：对方送来的完整帖子数据
- `data/private/`：68 款游戏的体验记录

如果上面有不想公开的，先不要推送，直接走第二部分。

### 步骤

1. 在 GitHub 网页新建一个仓库，例如 `webgame-monitor`，选 Public，**不要**勾选"Add a README"。
2. 在本机这个目录里执行（把地址换成你的）：
   ```bash
   git remote add origin git@github.com:<用户名>/webgame-monitor.git
   ```
   ```bash
   git push -u origin main
   ```
3. 仓库页面 → Settings → Pages → Build and deployment → Source 选 **GitHub Actions**。
4. Settings → Actions → General → Workflow permissions 选 **Read and write permissions**。
5. 打开 Actions 页，选"每日采集与发布"，点 **Run workflow** 手动跑一次。
6. 跑完后页面在 `https://<用户名>.github.io/webgame-monitor/`。把这个地址填进 `config.json` 的 `site.base_url`，汇总文本里就会带上链接。

之后每天北京时间 10:30 自动跑一次。第一次自动运行后请看一眼 Actions 的日志，确认各渠道都拿到了数据（海外机器访问 fxtwitter、HN、Spawn 这些接口还没有实测过）。

### X 数据的拉取地址（拿到之后）

Settings → Secrets and variables → Actions → New repository secret：

- `X_PULL_URL`：拉取地址，日期用 `{date}` 占位，例如 `https://example.com/x/{date}.json`
- `X_PULL_TOKEN`：如果需要鉴权才填。默认按 `Authorization: Bearer <令牌>` 发送，格式可以在 `config.json` 的 `x_pull.auth_header` 里改

地址和令牌放在仓库密钥里，不会出现在代码和日志中。如果这个地址只有公司内网能访问，GitHub 的机器拉不到，这一步要等迁到内部平台后再接。

## 二、迁到公司内部平台

页面是纯静态的，`site/` 目录拷到任何能托管静态文件的地方都能用。迁移时要确认内部平台的三件事：

| 要确认的 | 如果可以 | 如果不行 |
|---|---|---|
| 有没有定时任务（CI） | 把 `.github/workflows/daily.yml` 改写成对应平台的格式，命令还是 `python3 run.py daily` | 在本机或服务器上用定时器跑，跑完把 `site/` 推上去 |
| 定时任务的机器能不能访问外网（X 接口、HN、GitHub） | 采集直接在内部跑 | 采集留在 GitHub Actions，内部平台定时拉取 GitHub 仓库的数据后只跑 `python3 run.py site` |
| 有没有静态页面托管（类似 Pages） | 发布 `site/` 目录 | 把 `site/` 放到内网的静态服务器或对象存储 |

阿里云那台服务器访问不了 archive.org 和带 Cloudflare 验证的站点，能不能访问 X 接口、GitHub 还没有测过，所以没有把采集放在那里。

## 三、推送汇总

每次运行会生成：

- `digest/daily-<日期>.txt`：当天新增
- `digest/weekly-<周一日期>.txt`：本周新增（每天覆盖更新，周日的版本是整周的）

线上对应 `…/digest/daily-latest.txt` 和 `…/digest/weekly-latest.txt`。现在只生成文本，还没有接推送渠道。要推到 POPO 的话，定下推给谁、每天还是每周之后再接。
